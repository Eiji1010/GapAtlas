# 方法論と限界

GapAtlas が何を示し、何を示さないかを定義します。この文書の内容は UI にも反映します。

## 何を測っているか

GapAtlas が算出する **Need Gap Signal Score** は、次の観測に基づく指標です。

> ある国において、検索需要と困りごとの表出が増加している一方で、**検索結果上で見える解決策**が相対的に少ない

測定対象は **検索という窓を通して観測できる範囲** に限定されます。

## 何を示さないか

| 誤解 | 実際 |
|---|---|
| 社会問題の客観的な深刻度 | 測定していない。検索行動の変化を見ているだけ |
| 実際のサービス供給量 | 測定していない。検索上位に出るかどうかを見ている |
| 市場規模・TAM | 算出していない |
| 将来予測 | 行っていない |
| 国同士の絶対的な需要の大小 | 比較していない。Google Trends の値は期間・地域内の相対値 |
| ニュースが少ない = 問題がない | 成り立たない。報道量は問題の有無と直結しない |
| Maps の件数 = 事業者数 | 成り立たない。Maps は Core Score に使用しない |

## 各成分の限界

### Demand Momentum

Google Trends の 0〜100 は、指定した期間と地域の中で正規化された相対値です。国間で直接比較できません。GapAtlas は**変化率のみ**を使い、水準を比較しません。

検索ボリュームの少ない国・言語では系列が粗くなり、0 が多く含まれます。値の 50% 以上が 0 の場合、Evidence Confidence を 59 以下に制限します。

### Pain Signal

Rising Queries は「急上昇している検索語」であり、母数が小さいと極端な成長率が出ます。GapAtlas は成長率を `log1p` で圧縮し、さらに件数の少なさを Evidence Confidence の Sample sufficiency で扱います。

クエリの分類は LLM が行うため、言語・文化による誤分類が起こりえます。分類には confidence を持たせ、重みへ反映します。

### Solution Coverage Gap

**「検索上で見える Solution Coverage」であり、実際のサービス供給量ではありません。**

次の場合に実態と乖離します。

- 事業者が SEO に投資していない(供給はあるが検索に出ない)
- 情報サイトやまとめ記事が上位を占める(供給はあるが見えない)
- 検索語が事業者名ではなく制度名に寄っている

この乖離自体が「探しても見つけにくい」という意味を持ちますが、供給不足と同一視してはいけません。

### News Urgency

報道量は媒体の関心と報道慣行に強く依存します。全体重みを 10% に抑えているのはこのためです。ニュースが少ないことを問題の不在の根拠にしてはいけません。

## Evidence Confidence を分けている理由

スコアと確信度を混ぜると、「データが乏しいので低い」のか「データは十分で本当に低い」のかが区別できなくなります。GapAtlas は次のように分離します。

- **Need Gap Signal Score**: 観測されたシグナルの強さ
- **Evidence Confidence**: そのシグナルをどれだけ信用してよいか

利用者は両方を見て判断します。Confidence が低い国は「シグナルが弱い」のではなく「まだ判断材料が足りない」と読みます。

## AI の位置づけ

AI は次の2つにのみ使用します。

1. **分類**: 検索語・検索結果・記事をカテゴリへ振り分ける
2. **説明**: 算出済みの結果を人間が読める形にまとめる

AI はスコアを決定しません。AI が Evidence に存在しない事実を述べることを禁じ、生成文には Evidence ID(`E1` `E2` ...)の引用を必須とします。URL を AI に生成させません。

## 正しい使い方

GapAtlas の出力は **調査の出発点** です。

1. ランキング上位かつ Confidence が高い国を選ぶ
2. Country Evidence で、どの成分がスコアを押し上げているか確認する
3. Opportunity Brief の「WHAT THIS DOES NOT PROVE」を読む
4. 「NEXT VALIDATION」に沿って一次調査(現地ヒアリング、統計、規制調査)を行う

GapAtlas 単体で事業判断を行ってはいけません。
